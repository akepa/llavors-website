# Slice 5 — SEO básico

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** La web es indexable por Google con metaetiquetas únicas por página, hreflang bilingüe, datos estructurados LocalBusiness y sitemap automático.

**Architecture:** Un componente `SEO.astro` centraliza toda la lógica del `<head>` (title, description, OG, canonical, hreflang). Un `SchemaOrg.astro` separado genera el JSON-LD LocalBusiness solo en las homepages. `BaseLayout.astro` delega en ambos. El sitemap lo genera automáticamente `@astrojs/sitemap` en cada build.

**Tech Stack:** Astro 6, `@astrojs/sitemap`, TypeScript strict.

### Task 2: Crear `SEO.astro`

**Files:**
- Create: `src/components/SEO.astro`

- [ ] **Crear el componente**

Crear `src/components/SEO.astro` con este contenido completo:

```astro
---
interface Props {
  title: string
  description: string
  lang: 'ca' | 'es'
  ogImage?: string
  canonical?: string
  gscVerification?: string
}

const {
  title,
  description,
  lang,
  ogImage = '/og-default.jpg',
  canonical,
  gscVerification,
} = Astro.props

const SITE = 'https://www.llavorslogopedia.com'
const BASE = '/llavors-website'

// Elimina el base path de GitHub Pages para construir la URL canónica real
const rawPath = Astro.url.pathname.startsWith(BASE)
  ? Astro.url.pathname.slice(BASE.length) || '/'
  : Astro.url.pathname

const resolvedCanonical = canonical ?? `${SITE}${rawPath}`
const ogImageUrl = `${SITE}${ogImage}`

// Construye las URLs hreflang. Las URLs ca no llevan prefijo; las es llevan /es/.
const caUrl = lang === 'ca'
  ? resolvedCanonical
  : resolvedCanonical.replace(`${SITE}/es`, SITE)

const esUrl = lang === 'es'
  ? resolvedCanonical
  : resolvedCanonical.replace(SITE, `${SITE}/es`)
---
<title>{title} | Llavors Logopèdia</title>
<meta name="description" content={description} />

<meta property="og:title" content={title} />
<meta property="og:description" content={description} />
<meta property="og:image" content={ogImageUrl} />
<meta property="og:type" content="website" />
<meta property="og:url" content={resolvedCanonical} />

<meta name="twitter:card" content="summary_large_image" />

<link rel="canonical" href={resolvedCanonical} />

<link rel="alternate" hreflang="ca" href={caUrl} />
<link rel="alternate" hreflang="es" href={esUrl} />
<link rel="alternate" hreflang="x-default" href={caUrl} />

{gscVerification && <meta name="google-site-verification" content={gscVerification} />}
```
